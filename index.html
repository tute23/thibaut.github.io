Algorithm

send(p) runs at the beginning of each round and returns "beep", "listen", or in DBL/CO[1] "cw", "ccw", "both". Then the simulator computes observations and calls receive(p). In anonymous mode, non-leaders start with p.id = null, then your code may assign p.id = value.

Programming Specification

Round Cycle

function send(p) {
  return "listen";
}

function receive(p) {
  if (p.observation.heard) {
    p.memory.seen = true;
  }
}
  • send(p) runs for every process at the beginning of the round.
  • The simulator then computes observations using the current ring order.
  • receive(p) runs after that, with p.observation available.
  • p.memory persists across rounds for each process.

The p Object

  • p.id: current process identity. In anonymous mode, it starts as null for non-leaders and can then be changed with p.id = value.
  • p.index: internal debug identifier. Do not use it when testing an anonymous algorithm.
  • p.n: ring size in the simulator.
  • p.round: current round number, starting at 0.
  • p.isLeader: true only for the leader.
  • p.anonymous: true when anonymous mode is active.
  • p.memory: local object that the algorithm may mutate.
  • p.output and p.done: process output and termination state.
  • p.terminate(value): marks the process as terminated with output value.

Identity Table

  • The table maps a p.id value to a displayed name and color.
  • The null value represents initially unnamed anonymous processes.
  • If your code runs p.id = p.round, the node takes the name and color mapped to that value.
  • If a value does not exist yet, the simulator creates an entry automatically.

Actions in send(p)

  • "listen", "silent", "none": sends nothing.
  • "beep" or "both": sends to both neighbors.
  • "cw": sends clockwise only, useful in DBL or CO[1].
  • "ccw": sends counterclockwise only, useful in DBL or CO[1].

Observations in receive(p)

  • p.observation.heard: true if at least one signal is received.
  • p.observation.silent: true if no signal is received.
  • p.observation.cw: 1 if a signal arrives from the clockwise side.
  • p.observation.ccw: 1 if a signal arrives from the counterclockwise side.
  • p.observation.both: true if both sides send.

Models

  • BL: half-duplex, no direction. If a process sends, it receives nothing in that round.
  • DBL: directional half-duplex. A listening process distinguishes cw and ccw.
  • CO[1]: directional full-duplex. A process can receive while sending.
